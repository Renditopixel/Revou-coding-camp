Project Spec: To-Do List Dashboard



Project Type

Client-side To-Do List / Focus Timer app (HTML, CSS, JS)

Data Storage: LocalStorage on



Data Storage

\- LocalStorage untuk tasks

\- LocalStorage untuk quick links

\- LocalStorage untuk nama, tema, durasi timer



Features (MVP)

\- Live clock, update tiap detik

\- Greeting based on time of day (Morning/Afternoon/Evening/Night)

\- Focus timer 25 menit (default), Start/Stop/Reset buttons

\- Add, edit (inline), delete tasks

\- Mark tasks as done (checkbox)

\- Tasks saved to LocalStorage

\- Quick links buttons (Google, Gmail, Calendar by default)

\- Links saved to LocalStorage
